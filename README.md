# FTC Team 21813: DECODE Robot Code (2025-26)

Java robot code for our FIRST Tech Challenge team's DECODE season robot, built on the FTC SDK with FTCLib's command-based framework.

## What it does
- **Autonomous:** red and blue routines for close and far starts, with separate qualifier and playoff versions (including 6- and 15-artifact partner autos)
- **TeleOp:** velocity-controlled mecanum drive with a slow mode, plus intake, transfer, and eject controls on the gamepad
- **Shooter:** closed-loop RPM control with an adjustable hood, driven by a distance-to-RPM lookup table and a shoot-on-the-move (SOTM) calculation
- **Turret:** turret aiming at the alliance goal, with an operator offset for fine adjustment
- **Localization and vision:** goBILDA Pinpoint odometry, plus AprilTag camera relocalization
- **Tuning and testing:** FTC Dashboard live-tunable constants and test OpModes for each subsystem, including system identification

## Tech
Java, FTC SDK, FTCLib (command-based), FTC Dashboard, goBILDA Pinpoint
